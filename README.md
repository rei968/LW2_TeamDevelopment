# CineSphere 🎬 — Cinema Showcase & Ticket Booking Platform

> **Лабораторна робота №2 (LR2)**: Командна розробка програмного забезпечення, Git-flow, моделювання конфліктів злиття та забезпечення якості.

## 📌 1. Про проєкт

**CineSphere** — це сучасний інтерактивний веб-додаток для демонстрації кіноафіші та повноцінного бронювання місць у залі кінотеатру.  
Головна мета проєкту — **продемонструвати бездоганну командну роботу в Git** (галуження `feature/*`, Pull Requests на GitHub, рев'ю коду, інсценування та вирішення Merge Conflict, а також автоматизоване тестування бізнес-логіки).

### 💡 Ключові можливості:
- 🎞 **Інтерактивна афіша**: картки фільмів із постерами, тривалістю, віковими обмеженнями, рейтингом та описом.
- 🔍 **Пошук та фільтри**: швидкий пошук за назвою або режисером, фільтрація за жанрами (Sci-Fi, Action, Drama, Animation, Biography).
- 📅 **Вибір сеансу та формату**: перемикання між датами та часом показу (2D, 3D, IMAX).
- 💺 **Інтерактивна схема залу**: візуальний вигнутий екран (Curved Screen), поділ сидінь на категорії (**Standard**, **VIP**, **Дивани**), відображення вже зайнятих місць.
- ⚡ **Контроль замовлення**: ліміт до 6 місць на одне замовлення, динамічний розрахунок вартості, підтримка студентської знижки та промокодів (`STUDENT10`, `CINE20`).
- 🎟 **Цифровий ваучер**: генерація квитка з персональним штрих-кодом та унікальним номером бронювання (`CS-XXXXX`).
- 💾 **Повна автономність (Zero-Dependency)**: збереження стану та історії квитків у `LocalStorage` з можливістю скасування та вивільнення місць.
- 🧪 **Автоматизований QA-раннер**: вбудована сторінка автотестів `tests.html` для перевірки бізнес-правил.

## 🛠 2. Технічний стек

- **Frontend**: Семантичний HTML5, модульний CSS3 (дизайн-токени `variables.css`, Flexbox, CSS Grid, Glassmorphism, темна кінематографічна тема **Dark Neon Cinema**), чистий JavaScript (ES6+ модулі).
- **Сховище даних**: `LocalStorage API` з автоматичним сідінгом початкових даних (фільми, зали, сеанси).
- **Архітектура**: Чіткий поділ на шари:
  - `Persistence` (`js/db.js`) — робота зі сховищем LocalStorage;
  - `State & EventBus` (`js/state.js`) — реактивний стан обраних місць та сеансів;
  - `Domain Logic` (`js/booking.js`, `js/pricing.js`) — ціноутворення, перевірка зайнятості, оформлення квитків;
  - `UI Presentation` (`js/ui/*`, `index.html`, `css/*`) — компоненти відображення.
- **Тестування**: Автономний браузерний тестовий раннер (`tests.html`) без необхідності встановлення сторонніх бібліотек.

## 🚀 5. Швидкий запуск проєкту

Проєкт є **повністю автономним** і не потребує встановлення `Node.js`, `npm` або збирачів:

1. **Клонувати репозиторій собі на комп'ютер**:
   ```bash
   git clone https://github.com/rei968/LW2_TeamDevelopment.git
   cd LW2_TeamDevelopment
   git checkout develop
   git pull origin develop
   ```
2. **Запустити головний додаток**:
   - Двічі клікнути на файл `index.html` у провіднику Windows;
   - Або відкрити через будь-який локальний сервер (наприклад, розширення **Live Server** у VS Code).
3. **Запустити автоматизовані тести**:
   - Двічі клікнути на файл `tests.html` або перейти за посиланням «🧪 Тести» у верхньому меню сайту.

## 🌿 6. Правила роботи в Git для команди

> [!IMPORTANT]
> **НІКОЛИ НЕ ПУШТЕ ПРЯМО В `main` ЧИ `develop`!**  
> Кожен студент працює виключно у своїй гілці `feature/*` та надсилає зміни через Pull Request на GitHub.

### Стандартний робочий цикл студента:
1. Оновити локальний `develop`:
   ```bash
   git checkout develop
   git pull origin develop
   ```
2. Створити власну гілку:
   ```bash
   git checkout -b feature/ваше_ім_я-назва_задачі
   ```
3. Внести зміни у закріплені за вами файли, перевірити працездатність у браузері.
4. Зробити осмислений коміт за стандартом **Conventional Commits**:
   ```bash
   git add .
   git commit -m "feat(hall): додав підсвічування VIP-сидінь та анімацію вигнутого екрана"
   ```
5. Відправити гілку на GitHub:
   ```bash
   git push -u origin feature/ваше_ім_я-назва_задачі
   ```
6. Створити **Pull Request** на GitHub (цільова гілка — `develop`), пройти перевірку та отримати апрув від Тімліда (Же).
