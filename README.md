# CineSphere — Платформа онлайн-афіші та бронювання квитків

Лабораторна робота №2 з дисципліни «Технології командної розробки програмного забезпечення».  
Тема: Командна розробка додатків із використанням системи контролю версій Git, галуження Git Flow, моделювання та розв'язання конфліктів злиття (Merge Conflicts).

## 1. Опис проєкту

CineSphere — клієнтський веб-додаток для перегляду кіноафіші, фільтрації фільмів, вибору місць на інтерактивній схемі залу та оформлення електронного квитка.

Ключовий функціонал:
- Каталог фільмів з пошуком за назвою, фільтрацією за жанрами та детальними даними сеансів.
- Інтерактивна схема кінозалу з категоріями сидінь (Standard, VIP, Дивани), статусами доступності та вигнутим екраном.
- Система розрахунку вартості замовлення: динамічні націнки за категоріями, студентські знижки, промокоди (STUDENT10, CINE20) та об'єднане правило групових/VIP-знижок.
- Валідація замовлення: обмеження до 6 місць на клієнта, захист від повторного бронювання (Double-Booking Prevention), перевірка контактних даних.
- Електронний квиток-ваучер з перфорацією, статусом оплати та штрих-кодом.
- Автономне збереження стану та історії замовлень у Web Storage API (LocalStorage).

## 2. Стек технологій та архітектура

Проєкт реалізовано за концепцією Zero-Dependency (без використання сторонніх важких фреймворків чи зовнішніх бібліотек):
- Розмітка та оформлення: HTML5, CSS3 (дизайн-токени у variables.css, Flexbox, CSS Grid, адаптивна верстка).
- Мова програмування: Vanilla JavaScript (модульний стандарт ES6).
- Сховище даних: LocalStorage API з модулем початкового наповнення (db.js).
- Архітектурний патерн: Багатошарова модульна архітектура (Presentation Layer, State/EventBus, Domain Logic, Persistence Layer).
- Тестування: Власний браузерний тестовий раннер (tests.html) та автономний CLI-раннер (scripts/run_tests.mjs).

## 5. Інструкція із запуску та тестування

### 5.1. Запуск додатку
Проєкт не потребує компіляції. Доступні два способи запуску:

Спосіб 1 (за допомогою Node.js):
```bash
npm start
```
Додаток буде доступний за адресою: `http://localhost:8080/`

Спосіб 2 (без використання консолі):
Відкрити файл `index.html` у сучасному веб-браузері (Chrome, Firefox, Edge, Safari).

### 5.2. Виконання тестів
- У консолі:
  ```bash
  npm test
  ```
- У браузері:
  Відкрити сторінку `http://localhost:8080/tests.html` або двічі клікнути на файл `tests.html`.

## 6. Регламент роботи з Git

1. Основні гілки:
   - `main` — стабільна релізна версія; прямі коміти заборонені.
   - `develop` — інтеграційна робоча гілка.
2. Розробка функціоналу ведеться у тематичних гілках `feature/<ім'я>-<назва_задачі>`, що створюються від `develop`.
3. Злиття фіч у `develop` виконується виключно через механізм Pull Request після проходження тестів та рев'ю.
4. Повідомлення комітів відповідають конвенції Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`.
