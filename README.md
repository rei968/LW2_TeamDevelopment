# CineSphere 🎬 — Cinema Showcase & Ticket Booking Platform

> **Лабораторна робота №2 (LR2)**: Командна розробка програмного забезпечення, Git-flow, моделювання конфліктів злиття та забезпечення якості.

---

## 📌 Про проєкт

**CineSphere** — це сучасний веб-додаток для демонстрації кіноафіші та інтерактивного бронювання місць у кінотеатрі. Проєкт побудований на базі концепції **Zero-Dependency Vanilla Web** (чистий HTML5, CSS3, ES6 JavaScript та Web Storage API) і забезпечує повний цикл роботи клієнта:
- Перегляд актуальної афіші з фільтрацією за жанрами та пошуком;
- Інтерактивна вибірка сеансів та перегляд інформації про кінозал;
- Візуальна схема кінозалу з вигнутим екраном (Curved Screen), категоріями місць (Standard, VIP, Дивани) та динамічним оновленням статусу зайнятості;
- Вибір до 6 місць з миттєвим розрахунком вартості замовлення;
- Оформлення квитків з валідацією форми та генерацією цифрового ваучера з унікальним кодом бронювання (`CS-XXXXX`);
- Збереження історії бронювань у `LocalStorage` з можливістю скасування та вивільнення місць.

---

## 🛠 Технічний стек

- **Frontend**: Семантичний HTML5, модульний CSS3 (Custom Properties / Design Tokens, Flexbox, Grid, Glassmorphism, Neon Cinema Theme), Vanilla JavaScript (ES6+ Modules).
- **Сховище даних**: `LocalStorage API` з атомарними транзакціями, валідацією схеми та автозаповненням тестовими даними (Mock Seeder).
- **Архітектурний підхід**: Поділ на шари (Persistence -> State/EventBus -> Domain Logic -> UI Presentation).
- **Тестування**: Автономний in-browser тестовий раннер (`tests.html`) без сторонніх залежностей.

## 🌿 Git-стратегія та робочий процес

Проєкт використовує розширену модель **Git Flow**:
- `main` — стабільна виробнича гілка, містить лише релізні версії (тег `v1.0.0-cinesphere`);
- `develop` — основна інтеграційна гілка для об'єднання доробок команди;
- `feature/*` — ізольовані функціональні гілки розробників;
- **Conventional Commits**: `feat:`, `fix:`, `test:`, `docs:`, `chore:`, `style:`.

## 🚀 Як запустити проєкт

Проєкт не потребує встановлення додаткових бібліотек чи збірки:
1. Клонувати репозиторій або відкрити робочу директорію:
   ```bash
   git clone https://github.com/rei968/LW2_TeamDevelopment.git
   cd LW2_TeamDevelopment
   ```
2. Відкрити файл `index.html` у будь-якому сучасному веб-браузері (Chrome, Edge, Firefox, Safari):
   - подвійним кліком на `index.html`;
   - або через локальний веб-сервер (Live Server у VS Code, `npx serve`, чи `python -m http.server 8000`).
3. Для запуску автоматизованих тестів відкрити у браузері `tests.html`.
