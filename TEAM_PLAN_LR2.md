## 👨‍💻 Студент 1: Же (Team Lead & Frontend 1)

### Мета:
Організувати центральну вітрину кінотеатру, оптимізувати пошук та фільтри, провести код-рев'ю завдань та скоординувати фінальний реліз.

### Покрокова інструкція для Же:

1. **Створення робочої гілки**:
   ```bash
   git checkout develop
   git pull origin develop
   git checkout -b feature/zhe-catalog-ui
   ```

2. **Що потрібно зробити в коді**:
   - У файлі `css/components/catalog.css` покращити вигляд карток фільмів: додати ефект hover-зуму для постера фільму (`transform: scale(1.03)`), плавні тіні та неоновий контур при наведенні.
   - У `index.html` або `js/ui/catalogView.js` додати відображення бейджів формату показу (наприклад, `IMAX`, `3D`, `Dolby Atmos`) для сеансів.
   - Перевірити роботу фільтрів за жанрами (`Sci-Fi`, `Action`, `Drama`, `Animation`, `Biography`) та очищення пошукового рядка.

3. **Коміт та надсилання на GitHub**:
   ```bash
   git add css/components/catalog.css js/ui/catalogView.js index.html
   git commit -m "feat(catalog): вдосконалено вітрину фільмів, додано hover-ефекти та бейджі форматів показу"
   git push -u origin feature/zhe-catalog-ui
   ```

4. **Pull Request**:
   - Відкрити PR на GitHub у гілку `develop`.
   - Запросити рев'ю від Яріка чи Льоші.
   - Після схвалення виконати Merge.

   - У файлі `js/booking.js`:
     - Перевірити захист від вибору понад 6 місць на замовлення.

5. **Pull Request**:
