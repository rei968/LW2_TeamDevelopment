## 1. Мета та завдання роботи

### Мета:
Оволодіти практичними навичками організації командної розробки програмного забезпечення із застосуванням розподіленої системи контролю версій Git, вивчити та застосувати модель розгалуження Git Flow, засвоїти стандарти повідомлень комітів (Conventional Commits), виконати паралельну реалізацію функціональних модулів в ізольованих гілках, а також свідомо змоделювати, проаналізувати та вирішити реальний конфлікт злиття (Merge Conflict) у коді спільної бізнес-логіки.

### Основні завдання:
1. **Ініціалізація та налаштування репозиторію:** Очищення структури проєкту, фіксація базової архітектури та налаштування гілки `develop`.
2. **Розподіл ролей та зон відповідальності:** Створення структури гілок `feature/*` для кожного члена команди.
3. **Розробка архітектури системи CineSphere:** Створення модульного клієнтського веб-додатку без зовнішніх залежностей (Zero-Dependency Vanilla HTML5/CSS3/ES6 JS + LocalStorage API).
4. **Реалізація користувацького інтерфейсу:** Верстка каталогу фільмів, фільтрація за жанрами, пошук та відображення залів у гілці `feature/zhe-catalog-ui`.
5. **Моделювання та розв'язання Merge Conflict:**
   - Одночасне внесення несумісних змін у розрахунок знижок у файлі `js/pricing.js` (VIP-знижка 10% та групова знижка 15%);
   - Фіксація виникнення конфлікту при злитті гілки `develop` у робочу гілку;
   - Аналіз конфліктних маркерів Git;
   - Узгодження та інтеграція обох бізнес-правил в єдиний послідовний алгоритм;
   - Завершення коміту злиття та оновлення гілки `develop`.
6. **Забезпечення якості (QA):** Розробка та виконання набору з 21 автоматизованого тесту в браузерному середовищі `tests.html` та CLI-раннері `scripts/run_tests.mjs`.
7. **Фіксація артефактів:** Формування контрольних точок (Checkpoints) з історією виконання операцій та графом комітів.

## 2. Архітектура та стек технологій

Додаток побудовано за принципом багатошарової модульної архітектури без використання сторонніх бібліотек чи фреймворків:

```text
CineSphere Client Architecture:
┌─────────────────────────────────────────────────────────────────┐
│                     Презентаційний шар (UI)                     │
│   index.html | css/variables.css, main.css, components/*.css   │
│   js/ui/catalogView.js | js/ui/hallView.js | js/ui/modalView.js │
└───────────────────────────────┬─────────────────────────────────┘
                                │ Події користувача / Рендеринг
┌───────────────────────────────▼─────────────────────────────────┐
│                  Шар реактивного стану (State)                  │
│   js/state.js — CineSphereStateStore (PubSub шина подій)        │
└───────────────────────────────┬─────────────────────────────────┘
                                │ Виклики бізнес-логіки
┌───────────────────────────────▼─────────────────────────────────┐
│               Шар предметної логіки (Domain Logic)              │
│   js/pricing.js — Розрахунок цін, націнок, знижок та промокодів │
│   js/booking.js — Матриця залу, валідація, захист від колізій   │
└───────────────────────────────┬─────────────────────────────────┘
                                │ Читання / Запис даних
┌───────────────────────────────▼─────────────────────────────────┐
│                   Шар персистентності (Storage)                 │
│   js/db.js — Клієнтська БД з автопосівом (LocalStorage API)     │
└─────────────────────────────────────────────────────────────────┘
```

### Основні модулі системи:
- **`js/db.js`**: Рівень збереження даних на базі LocalStorage. Реалізує автопосів початкових даних (фільми, кінозали, розклад сеансів, тестові бронювання).
- **`js/state.js`**: Централізоване сховище стану на патерні Observer/PubSub для координації взаємодії між компонентами інтерфейсу.
- **`js/pricing.js`**: Модуль розрахунку вартості замовлення, націнок за категорії місць (VIP, Дивани), перевірки промокодів та об'єднаних правил знижок.
- **`js/booking.js`**: Контролер оформлення квитків із валідацією полів клієнта, лімітом кількості місць (до 6) та захистом від подвійного бронювання.
- **`tests.html` / `scripts/run_tests.mjs`**: Модулі автоматизованого тестування (BDD-стиль: `describe`, `it`, `expect`).

## 5. Моделювання та розв'язання Merge Conflict

Відповідно до вимог лабораторної роботи, команда змоделювала та успішно розв'язала конфлікт одночасного редагування спільного файлу бізнес-логіки.

### Локалізація конфлікту:
- **Файл:** `js/pricing.js`
- **Функція:** `calculateOrderTotal(params)`
- **Причина колізії:** Одночасне додавання двох різних правил нарахування знижки в одному місці функції.

---

### Етап 1. Зміни першого розробника (Ярослав — VIP-знижка)
У гілці `feature/yarik-vip-discount` реалізовано знижку 10% для клієнтів з VIP-місцями:
```javascript
  const hasVipSeats = seats.some(s => s.tier === 'vip');
  if (hasVipSeats) {
    discountRate = 0.10; // Знижка 10% для поціновувачів комфорту (Ярік)
  }
```
Коміт: `f6746c4` (`feat(pricing): додано знижку 10% на замовлення з VIP-місцями`).  
Гілка була злита в `develop` через коміт `427544c`.

---

### Етап 2. Зміни другого розробника (Же — Групова знижка)
У паралельній гілці `feature/zhe-bulk-discount` змінено ті самі рядки для підтримки групової знижки 15% (від 3 квитків):
```javascript
  if (seats.length >= 3) {
    discountRate = 0.15; // Групова знижка 15% для компаній від 3 осіб (Же)
  }
```
Коміт: `80bcb9d` (`feat(pricing): додано знижку 15% для замовлень від 3 квитків`).

### Етап 5. Узгодження та інтеграція коду
Команда прийняла рішення зберегти обидва правила лояльності та структурувати їх відповідно до єдиної ієрархії пріоритетів (Промокод -> Студентська знижка -> Групова знижка -> VIP-знижка):

```javascript
  const upperCode = (promoCode || '').trim().toUpperCase();
  let discountLabel = null;
  const hasVipSeats = seats.some(s => s.tier === 'vip');

  // Об'єднана логіка після вирішення Merge Conflict:
  if (upperCode && PROMO_CODES[upperCode]) {
    discountRate = PROMO_CODES[upperCode].discountPercent / 100;
    isPromoValid = true;
    discountLabel = PROMO_CODES[upperCode].label;
  } else if (isStudent) {
    discountRate = 0.15;
    discountLabel = 'Студентська знижка (-15%)';
  } else if (seats.length >= 3) {
    discountRate = 0.15; // Знижка для компаній (від Же)
    discountLabel = 'Групова знижка від 3 квитків (-15%)';
  } else if (hasVipSeats) {
    discountRate = 0.10; // Знижка на VIP (від Яріка)
    discountLabel = 'VIP-знижка (-10%)';
  }
```
